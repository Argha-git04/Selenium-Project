# 🚀 Selenium Python Automation Project

A comprehensive **Selenium Python Automation Framework** developed as part of **Capstone Assignment 2**, focusing on web automation, structured test development, reusable components, test data management, reporting, and failure handling.

This repository also contains certificates from completed Coursera courses covering **Python Automation, Selenium WebDriver, Playwright, and Robot Framework**.

---

## 📌 Project Overview

The objective of this project is to design and implement a maintainable Selenium automation framework for an **E-Commerce application**.

The framework demonstrates practical implementation of:

- Selenium WebDriver
- Python
- PyTest
- Unittest
- Page Object Model (POM)
- Utility classes
- Configuration management
- CSV-based test data
- Automated screenshots on test failure
- HTML test reporting
- Modular and reusable test components

The project focuses on creating an organized automation structure that can be extended for larger web testing projects.
